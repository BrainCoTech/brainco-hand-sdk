# Writing Profile

- Applies to: Public README files, C/C++ and Python example guides, platform setup, device integration notes, changelog entries, and example reviews.
- Selected items: `core`, `sdk-docs`, `portable-md`, `public-docs`.
- Conditional items:
  - Use `zh-cn` for Chinese documentation.
  - Use `en-sdk` for English SDK or example documentation.
  - Use `cross-role` for protocol, hardware, compatibility, or integration documents shared across SDK, firmware, robotics, application, test, support, or delivery roles.
  - Use `release-notes` for `CHANGELOG.md` and release summaries.
- Local overrides: Preserve the Revo1/Revo2 product scope, supported transport matrix, C/Python example equivalence, platform prerequisites, and distinction between current `c/` examples and archived platform-specific examples. Do not present archived examples as the recommended integration path.
